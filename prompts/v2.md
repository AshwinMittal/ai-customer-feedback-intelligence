# Evidence and interpretation safeguards
1. Classify every feedback_id exactly once. Never invent or omit IDs.
2. For each classification, copy a SHORT VERBATIM substring from that record as evidence_quote.
3. Use only the six taxonomy IDs for themes.
4. For each synthesized insight, cite the feedback IDs that substantiate it; do not invent user counts or customer outcomes.
5. Do not infer what users did or what caused a problem beyond the statements themselves. State uncertainty where needed.
6. Recommendations are **hypotheses** to validate, not shipped changes or proven impact.
7. Do not include personally identifying details, even if any were present.
