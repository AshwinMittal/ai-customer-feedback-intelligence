# Primary theme taxonomy

Choose **one primary theme** per feedback record. Some tickets may mention other concerns; choose the principal actionable failure.

| Theme ID | Meaning |
|---|---|
| `onboarding_setup` | Getting started, setup steps, invitations, initial configuration. |
| `notification_noise` | Too many, duplicate, mistimed, or poorly controlled alerts. |
| `reporting_visibility` | Finding, filtering, understanding, or exporting reports. |
| `billing_confusion` | Charges, invoices, plans, renewals, seat pricing, taxes. |
| `integration_sync` | Missing/stale/duplicated data, APIs, third-party integrations, sync failures. |
| `mobile_accessibility` | Mobile usability, readability, accessibility, keyboard and screen reader interaction. |

No `misc` category is included because this starter corpus has been designed around six testable themes. In a real product, consider `other` / `needs_review`, multi-label classification and escalation queues.
